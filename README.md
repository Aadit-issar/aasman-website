# Aasman website

Static homepage, privacy policy and terms of service for Aasman, a private single-owner personal AI assistant. Published with GitHub Pages to satisfy Google OAuth consent-screen branding requirements.

- Plain HTML plus one CSS file; no JavaScript, trackers, external fonts or CDNs.
- Contact route: this repository's Issues page. Do not post private data.
- Aasman is not a public service and is not affiliated with or endorsed by Google.
